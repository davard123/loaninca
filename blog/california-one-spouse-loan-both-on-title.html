加州夫妻买房只用一个人的名字贷款，另一个人能上 title 吗？以后想加名字怎么办？

简短回答：能。贷款只写一个人，产权（title）可以写两个人；在加州，没上贷款的配偶通常也要签抵押文件（deed of trust），但不因此成为借款人。以后只在产权上加配偶，一般不用重新贷款，地税也不因此重估。

贷款上的名字决定谁欠钱，产权上的名字决定房子归谁，这两样可以不同。H4 配偶没收入、贷款写谁的名字，已经在另一页讲过；这一页讲产权怎么写，和以后怎么加名字。

不上贷款、上产权，要签什么

加州婚后取得的财产一般是共同财产（Family Code §760），夫妻共同的房产要设定抵押，双方都要签字（Family Code §1102）。贷款规则和这一点衔接：Fannie Mae B8-2-03 要求，凡是对房子有所有权的人都要签抵押文件，即使他的收入没用来申请贷款。

签抵押文件和签借款合同（note）是两回事。Fannie Mae/Freddie Mac 通用的加州信托契据 Form 3005第 14 节写明：只签信托契据、没签 note 的人，是把自己在房子上的权益押给贷款机构，个人没有义务偿还这笔贷款。你实际签的文件如果不是这个格式，以你签的为准。

产权怎么写

加州夫妻常见几种写法：

  • Community property with right of survivorship：一方去世后，房子不经遗产程序直接归另一方（Civil Code §682.1）。
  • Community property 或 joint tenancy：各有不同的继承和税务后果。
  • 只写一个人：产权公司可能要另一方签一份放弃权益的文件，这会改变配偶的权利。

哪种写法适合你，涉及遗产和税务，请问律师或会计师，产权公司（title company）可以解释各种写法的格式。

以后想加名字怎么办

  1. 只在产权上加配偶：夫妻之间改变房产的性质，要有书面的明确声明，而且登记后才对外人生效（Family Code §852）。用哪种契据、怎么登记，问产权公司或律师。
  2. 贷款不受影响：联邦法律规定，房子转让使借款人的配偶成为所有人时，贷款机构不能因此要求你提前还清（12 U.S.C. §1701j-3(d)(6)）。
  3. 地税不重估：配偶之间的转让，包括只在配偶之间新增或取消共有人，不算 change of ownership（Revenue and Taxation Code §63）。
  4. 把配偶加为借款人：这要重新贷款，按当时的条件重新审核。

举例

这是为了说明规则而设的例子，不是真实客户。小周年收入够高，一个人做借款人；太太刚毕业还没工作。过户时两人都上产权，写成 community property with right of survivorship。签字那天，小周签 note 和信托契据，太太只签信托契据和产权相关文件。太太不欠这笔贷款，但房子有她一份。如果当初只写了小周一人，几年后再给太太加名字，要签夫妻间的转让契据并登记，贷款不变，地税也不因此重估。

常见问题

婚前我一个人买的房子，婚后加配偶名字算什么？

婚前的房子一般是个人财产，加配偶名字可能把它变成共同财产或共有财产，这在加州法律上叫 transmutation，要书面并登记（Family Code §852）。离婚和继承时后果很大，先问律师。

只上产权、不上贷款，以后卖房或重新贷款要他签字吗？

要。他是产权人，卖房要签；重新贷款时，产权人也要签抵押文件（Fannie Mae B8-2-03）。

产权写两个人，另一个人的债务会影响我的贷款吗？

看贷款类型。FHA 在共同财产州要把没上贷款的配偶的债务算进去，conventional 各家做法不同，见夫妻一起贷还是一个人贷那一页。

  • California Family Code §1102：共同不动产设定抵押须夫妻双方签字
  • California Family Code §852：夫妻间改变财产性质须书面
  • California Civil Code §682.1：Community property with right of survivorship
  • California Revenue and Taxation Code §63：配偶间转让不算 change of ownership
