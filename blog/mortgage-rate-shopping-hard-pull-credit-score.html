多家比价会被 hard pull 几次、掉多少分？经纪说是 soft pull 结果是 hard pull 怎么办？

每家正式查一次就记一次 hard pull，但 CFPB 写明，45 天内多家房贷机构的查询，在信用报告上只按一次计；FICO 的说法是，多一次查询，大多数人掉不到 5 分。

Hard pull（硬查询）是你申请贷款时，贷款机构调你的信用报告。Soft pull（软查询）是你自己查分，或机构做初步筛选，不影响分数。

时间窗口是 45 天还是 14 天

  • CFPB：只要最后一次查询和第一次相隔不超过 45 天，问几家，对信用的影响都一样。
  • FICO：旧版评分公式的窗口是 14 天，新版是 45 天，用哪个版本由贷款机构选。FICO 还说，房贷这类查询，评分前 30 天内发生的不计入分数。
  • 稳妥的做法：把比价集中在两周内做完。FICO 自己也这么建议。

会掉多少分

FICO 的说法：查询对分数影响小，大多数人多一次查询掉不到 5 分；账户少、信用历史短的人，影响会大一些。查询在报告上最多留两年，只在一年内影响 FICO 分数。

更要小心的是另一件事：办房贷期间去申请信用卡或车贷。那是另外的查询，CFPB 建议在申请房贷前和办理期间尽量避免。

比价时怎么做

  1. 先自己查一遍信用报告。自己查不掉分，有错先改。
  2. 选定几家后，让它们在同一两周内查，拿到 Loan Estimate 再比。
  3. 授权之前问一句：这次是 hard pull 还是 soft pull？哪一步才需要 hard pull？

说好 soft pull，结果成了 hard pull

先看信用报告，确认这条查询是谁查的、哪天查的。如果它和你其他房贷查询落在同一个窗口里，按上面的规则，对分数的额外影响有限。如果你根本没有授权这次查询，可以要求那家机构说明，并向征信机构提出异议（dispute）；解决不了，可以向 CFPB 投诉。

举例

这是为了说明规则而设的例子，不是真实客户。假设小林在 3 月 3 日到 3 月 12 日之间找了三家贷款机构，每家都查了一次信用。三次都在 14 天内，不管按旧版还是新版 FICO 公式，计分时都当一次查询。如果第三家拖到 5 月才查，离第一次超过了 45 天，就会算作另一次查询；按 FICO 的说法，多这一次，大多数人掉不到 5 分。

相关追问

Pre-approval 一定要 hard pull 吗？

各家做法不同。有的机构先用 soft pull 做初步评估，到正式申请才 hard pull。授权之前问清楚。CFPB 说，在 45 天窗口内可以拿多份 pre-approval 和 Loan Estimate。

超过 45 天还没定下来，还要不要继续比？

CFPB 的看法是通常仍然值得：多一次查询的影响小，而比价可能在长期省下不少钱。

查询记录多久消失？

按 FICO 的说明，hard pull 在信用报告上最多留两年，但只在一年内影响 FICO 分数。

自己查信用分会掉分吗？

不会。CFPB 和 FICO 都写明，自己查信用报告或信用分属于 soft pull，不影响分数。
